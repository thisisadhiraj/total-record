# CallRecorder Lite (Android)

Ultra-lightweight native Kotlin call recorder (minSdk 29 / targetSdk 35) for cellular and VoIP calls (WhatsApp, WhatsApp Business, Telegram, Messenger).

## Build APK on GitHub Actions
1. Create a new repository on GitHub and upload **all contents** of this folder (including the hidden `.github/` folder).
2. Open the **Actions** tab in your GitHub repository.
3. Wait for the **Build Android APK** workflow to finish (or click **Run workflow**).
4. Download **CallRecorderLite-release-apk** from the workflow **Artifacts** section and install the APK on your Android phone.
